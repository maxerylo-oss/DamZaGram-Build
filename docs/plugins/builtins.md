# Встроенные плагины DamZaGram

DamZaGram поставляется с тремя плагинами: экспорт чата, статистика чата и
тема DamZaGram. Они написаны на том же публичном API, что и плагины
пользователей, так что их код в
[`plugins/builtin/`](../../plugins/builtin) годится как образец.
Автор всех встроенных плагинов — [@wetakush](https://t.me/wetakush).

Клиент раскладывает их в `tdata/plugins/<id>/` при запуске и обновляет,
когда в новой версии клиента вшита более новая версия плагина. Встроенные
плагины, которые клиент больше не поставляет, он при запуске удаляет сам
(об этом ниже, в [«Плагины, которых больше нет»](#плагины-которых-больше-нет)).
Включить, выключить и настроить любой из них можно в **Настройки →
Плагины**. Все три включены сразу. Удалить встроенный плагин нельзя,
только выключить. Как устроена установка, описано в
[api/builtin.md](api/builtin.md).

| Плагин | Что делает | Как вызвать | По умолчанию |
|---|---|---|---|
| [Экспорт чата](#экспорт-чата-chat-export) | История чата в HTML, Markdown или JSON | меню чата, `/export` | вкл |
| [Статистика чата](#статистика-чата-chat-stats) | Авторы, часы, слова, медиа | меню чата, `/stats` | вкл |
| [Тема DamZaGram](#тема-damzagram-damza-theme) | Фирменные акценты Monolith / Glass / Rail | главное меню, `/theme` | вкл, Monolith |

Все команды пишутся прямо в поле ввода любого чата. Сообщение с командой
никуда не отправляется.

Горячие клавиши клиента:

| Сочетание | Что делает |
|---|---|
| **Ctrl+Shift+P** | Менеджер плагинов («Настройки → Плагины»). Работает, когда фокус не в поле ввода: в поле ввода это сочетание по-прежнему оформляет спойлер |

## Экспорт чата (`chat-export`)

Сохраняет историю любого чата, группы или канала в файл. Сообщения в
файле идут от старых к новым. Форматы, можно сразу несколько:

- **HTML** — одна самодостаточная страница: пузыри сообщений, разделители
  по дням, имена авторов разными цветами, ответы с цитатой (клик ведёт к
  оригиналу), пересылки, реакции, кнопки ботов, разметка и спойлеры.
  Светлая и тёмная тема (по системе или принудительно), лаймовый акцент
  `#C8F135`, внизу «Экспортировано DamZaGram». Открывается в любом
  браузере без интернета.
- **Markdown** — расшифровка на обычном CommonMark: заголовки по дням,
  `**Автор** · время`, ответы цитатой, медиа заглушками (`[Фото · 1280×720 · 244 КБ]`,
  `[Голосовое сообщение · 0:42]`, `[Файл · отчёт.pdf · 3,0 МБ]`…), пометки
  словами: «изменено», «удалено», «закреплено», «N просм.».
- **JSON** — шапка с информацией о чате и массив объектов `Message` в том
  виде, в каком их отдаёт API плагинов.

Как вызвать:

- **меню чата → «Экспорт чата…»** или `/export` без параметров —
  окно с настройками: сколько сообщений (`100`, `1000`, `10000`, `все`,
  любое число или `5k`, считая от самых новых), необязательный период «с
  даты / по дату» (`ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`, «по» включительно),
  форматы и «Включать служебные сообщения». Выбор запоминается;
- **`/export` с параметрами** сразу запускает экспорт, порядок слов не
  важен.

| Команда | Что делает |
|---|---|
| `/export` | Окно экспорта для текущего чата |
| `/export html 1000` | Последние 1000 сообщений в HTML |
| `/export md все` | Вся история в Markdown |
| `/export json html 500` | Последние 500 сразу в JSON и HTML |
| `/export json 2026-01-01 2026-03-31` | Всё за период (одна дата — с неё до сегодня) |
| `/export html все служебные` | Со служебными сообщениями (`-служебные` — без них) |
| `/export stop` | Остановить текущий экспорт |
| `/export list` | Последние экспорты: открыть файл, открыть папку |
| `/export folder` | Открыть папку с экспортами |
| `/export help` | Подсказка по командам |

Пока идёт экспорт, справа открыта панель: полоска с процентом, сколько
сообщений выгружено, скорость, оставшееся время и до какой даты уже
дошли. **«Остановить и сохранить»** сохраняет уже выгруженное (самые
новые сообщения), **«Отменить экспорт»** прекращает без сохранения. Панель
можно закрыть, экспорт продолжится. Когда всё готово, приходит
уведомление «Экспорт готов», его кнопка «Открыть» открывает папку. В
панели результата: открыть каждый файл, открыть папку, скопировать путь,
отправить в Избранное, экспортировать ещё.

Файлы сохраняются в
`tdata/plugins_data/chat-export/exports/<Чат>-<ГГГГ-ММ-ДД>.<html|md|json>`;
если имя занято, добавляется `-2`, `-3`…

| Настройка | По умолчанию | |
|---|---|---|
| Формат по умолчанию | HTML | Для `/export` без формата и первого открытия окна |
| Сколько сообщений по умолчанию | 1 000 | 100, 1 000, 10 000 или все |
| Включать служебные сообщения | нет | |
| Ссылки t.me на сообщения в группах и каналах | да | Время сообщения становится ссылкой |
| Тема HTML-страницы | как в системе | Или всегда светлая / тёмная |
| Максимум сообщений за один экспорт | 100 000 | Предел для «все», 1 000–1 000 000 |
| Пауза между страницами истории, мс | 150 | Страница — 100 сообщений, пауза бережёт от FLOOD_WAIT |
| Открывать файл сразу после экспорта | нет | |

Как это работает и ограничения:

- История грузится страницами по 100 сообщений (`dzg.messages.iterate`),
  между страницами плагин делает паузу и отдаёт управление клиенту, так
  что интерфейс не подвисает даже на десятках тысяч сообщений. Для
  периода плагин сразу переходит к нужной дате.
- На `FLOOD_WAIT_N` плагин ждёт N секунд (в панели идёт отсчёт) и
  продолжает с того же сообщения, без дублей. Сбои сети повторяются с
  нарастающей паузой. Ожидание дольше 15 минут или постоянная ошибка
  останавливают экспорт; загруженное можно сохранить кнопкой «Сохранить
  загруженное».
- Медиа не скачиваются: в файле остаются подписи и заглушки с типом,
  размером, длительностью и именем файла.
- Все выбранные форматы собираются в памяти: примерно 40 млн символов на
  все форматы вместе, это порядка 80–100 тыс. сообщений в HTML. Если
  экспорт упирается в предел, он сохраняет самые новые сообщения и пишет
  об этом в файле и в панели; остальное удобно выгрузить по периодам.
- Одновременно идёт только один экспорт. Экспорт работает с активным
  аккаунтом и останавливается, если переключить аккаунт (загруженное
  можно сохранить).
- Ссылки `t.me` на сообщения бывают только в супергруппах и каналах.
- Файлы лежат на диске в открытом виде — относись к ним как к самой
  переписке.

## Статистика чата (`chat-stats`)

`/stats` или пункт меню чата **«Статистика чата»** загружает последние
сообщения с сервера и показывает:

- сколько сообщений и за какой период, сколько в среднем в день, самый
  активный день, сколько ответов, пересылок, ссылок и правок;
- кто пишет больше всех: место, число сообщений, доля и полоска;
- активность по часам: 24 строки с текстовым графиком;
- активность по дням недели;
- частые слова без предлогов и союзов (русские и английские стоп-слова
  плюс свои);
- любимые эмодзи и типы медиа.

Внизу кнопки «Скопировать отчёт», «Отправить в этот чат» (с
подтверждением) и «Посчитать по 2N сообщениям». `/stats 3000` задаёт
число сообщений вручную, максимум 5000.

| Настройка | По умолчанию | |
|---|---|---|
| Сколько последних сообщений анализировать | 1000 | |
| Сколько авторов показывать | 8 | |
| Сколько слов показывать | 12 | |
| Свои стоп-слова | — | Через пробел или с новой строки |

## Тема DamZaGram (`damza-theme`)

Перекрашивает фирменными акцентами любую тему: кнопки, ссылки, бейджи,
переключатели, выбранный чат в списке и исходящие сообщения. Фон и
основной текст остаются от твоей темы. Для ночного и дневного режима
заданы свои оттенки, и при переключении режима плагин перекрашивает всё
сам.

| Пресет | Ночью | Днём |
|---|---|---|
| **Monolith** (по умолчанию) | лайм `#C8F135` с тёмным текстом на кнопках, оливковые исходящие | более глубокий лайм `#8DC21F`, светло-салатовые исходящие |
| **Glass** | тёплый коралл `#FF8A5B` | коралл `#F2703F`, персиковые исходящие |
| **Rail** | оранжевый `#C2410C`, ржавый выбранный чат | оранжевый `#C2410C`, кремовые исходящие |
| **None** | цвета текущей темы | |

Все пары цветов проверены на читаемость по WCAG: текст на кнопках не
ниже 4.5:1 (и под мышью), ссылки и имена в исходящих не ниже 4.5:1, текст в
исходящих не ниже 7:1. Галочки в чекбоксах рисуются цветом текста на
кнопках. Цвет выбранной папки на боковой панели плагин подбирает по её
настоящему фону: в дневной теме по умолчанию панель тёмная.

- `/theme` или пункт главного меню «Тема DamZaGram» — панель с выбором
  пресета и переключателями;
- `/theme monolith`, `/theme glass`, `/theme rail`, `/theme none`.

| Настройка | По умолчанию | |
|---|---|---|
| Пресет | Monolith | |
| Применять и в дневном режиме | да | |
| Красить исходящие сообщения | да | |
| Красить выбранный чат в списке | да | |

## Свой плагин вместо встроенного

Встроенный плагин — это обычная папка в `tdata/plugins/<id>/`. Его можно
открыть, почитать и поменять. Если в его `manifest.json` есть
`"builtin": true`, клиент перезапишет твою правку при следующем
обновлении плагина. Чтобы оставить правку, убери эту строку: клиент
перестанет трогать плагин, и он станет твоим. Чтобы вернуть встроенную
версию, удали папку, и при следующем запуске клиент поставит плагин заново.

## Плагины, которых больше нет

Раньше с клиентом шли ещё одиннадцать плагинов: командная палитра,
ИИ-дайджест, удалённые сообщения, напоминания, ключевые слова,
автоответчик, текстовые инструменты, антиреклама, автоматизации, быстрые
ответы и закладки. Теперь клиент их не поставляет. При запуске он удаляет
из `tdata/plugins/` папки встроенных плагинов, которых больше нет в его
сборке: только те, у которых в `manifest.json` стоит `"builtin": true` и
`id` совпадает с именем папки. Не трогает он:

- плагин, из манифеста которого ты убрал `"builtin": true`, — он уже твой;
- папку-симлинк (или junction в Windows) — это живая копия разработчика.

Файлы, которые эти плагины успели записать в `tdata/plugins_data/`
(журналы, закладки, правила), клиент не удаляет.
