# Встроенные плагины DamZaGram

DamZaGram поставляется с десятью плагинами. Они написаны на том же
публичном API, что и плагины пользователей, так что их код в
[`plugins/builtin/`](../../plugins/builtin) годится как образец.
Автор всех встроенных плагинов — [@wetakush](https://t.me/wetakush).

Клиент раскладывает их в `tdata/plugins/<id>/` при запуске и обновляет,
когда выходит новая версия. Включить, выключить и настроить любой из них
можно в **Настройки → Плагины**. Удалить встроенный плагин нельзя, только
выключить. Как устроена установка, описано в [api/builtin.md](api/builtin.md).

| Плагин | Что делает | Как вызвать | По умолчанию |
|---|---|---|---|
| [Командная палитра](#командная-палитра-command-palette) | Поиск по чатам, командам и действиям | **Ctrl+Shift+K**, `/palette` | вкл |
| [ИИ-дайджест](#ии-дайджест-что-я-пропустил-ai-digest) | Claude пересказывает чат | ✨ в шапке чата, `/digest` | вкл, нужен ключ |
| [Удалённые сообщения](#удалённые-сообщения-deleted-alerts) | Уведомления об удалениях и журнал | `/deleted` | вкл |
| [Напоминания](#напоминания-reminders) | Напомнить о сообщении или деле | `/remind 10m …`, меню сообщения | вкл |
| [Статистика чата](#статистика-чата-chat-stats) | Авторы, часы, слова, медиа | `/stats`, меню чата | вкл |
| [Ключевые слова](#ключевые-слова-keyword-alerts) | Уведомление о нужных словах в любом чате | `/keywords`, `/kw` | вкл |
| [Автоответчик](#автоответчик-auto-reply) | «Я не в сети» в личке | `/away on`, главное меню | **выкл** |
| [Текстовые инструменты](#текстовые-инструменты-text-tools) | Калькулятор, раскладка, base64 | `/calc`, `/tr`, меню сообщения | вкл |
| [Антиреклама](#антиреклама-anti-ads) | Скрывает рекламные посты | `/antiads`, меню канала | вкл |
| [Тема DamZaGram](#тема-damzagram-damza-theme) | Фирменные акценты Monolith / Glass / Rail | `/theme`, главное меню | вкл, Monolith |

Все команды пишутся прямо в поле ввода любого чата. Сообщение с командой
никуда не отправляется. Полный список команд показывает палитра: нажми
**Ctrl+Shift+K** и набери `>` или `/`.

## Командная палитра (`command-palette`)

Одно окно для всего клиента. **Ctrl+Shift+K** открывает панель с полем поиска,
повторное нажатие закрывает её. Сочетание работает и в русской раскладке
(Ctrl+Shift+Л). Поиск идёт сразу по трём источникам:

- **чаты**: по имени и @username, с пометками о непрочитанных, архиве и
  выключенном звуке;
- **команды всех плагинов**: выбор вставляет `/команда ` в поле ввода,
  остаётся дописать аргументы и нажать Enter;
- **действия клиента**: ночной режим, Избранное, все разделы настроек
  (папки, уведомления, конфиденциальность, сеансы, оформление, язык,
  память, прокси, горячие клавиши), настройки AyuGram, контакты, новая
  группа или канал, звонки, папка плагинов, перезапуск. Для открытого
  чата есть ещё: прочитать, заглушить или включить звук, архивировать,
  скопировать ссылку и id;
- **плагины**: включить или выключить любой плагин, открыть менеджер
  плагинов или DevTools.

Поиск нечёткий: `впк` найдёт «Вася Пупкин». Запрос в другой раскладке
тоже работает: `dfcz` найдёт «Вася». Чем чаще и недавнее ты что-то
выбирал, тем выше оно в списке.

| Префикс | Что ищет |
|---|---|
| `@имя` | только чаты |
| `>слово` | только команды и действия |
| `/имя` | только команды |
| `?текст` | поиск по сообщениям во всех чатах (на сервере); Enter открывает найденное сообщение |

**Enter** открывает первый результат, клик открывает любой. Палитру
также открывают `/palette` и пункт главного меню «Командная палитра».
При первом запуске DamZaGram палитра сама напомнит о себе подсказкой.

| Настройка | По умолчанию | |
|---|---|---|
| Горячая клавиша | `Ctrl+Shift+K` | Синтаксис Qt: `Ctrl+Shift+Space`, `Alt+P`. `Ctrl+Shift+P` уже занят менеджером плагинов |
| Сколько результатов показывать | 10 | от 3 до 30 |
| Искать по чатам / командам / действиям | да | Можно выключить любой источник |
| Показывать чаты из архива | да | |

## ИИ-дайджест «Что я пропустил» (`ai-digest`)

Пересказывает последние сообщения чата через Claude (Anthropic Messages API).
Получается суть одной строкой, 3–7 главных тем с кнопками **«↪ к сообщению»**
и отдельный блок **«Тебе:»**, если кто-то обращался к тебе или ждёт ответа.

Как вызвать:

- кнопка **✨** в шапке открытого чата;
- пункт **«✨ Что я пропустил»** в меню чата;
- `/digest` или `/digest 200`, чтобы задать число сообщений.

Если в чате есть непрочитанные, а настройка «Если есть непрочитанные…»
включена, плагин пересказывает именно их и ещё около 15 сообщений до них
для контекста. Иначе берёт столько сообщений, сколько указано в настройках
(не больше 500). Под дайджестом есть кнопки «Скопировать», «Сохранить в
Избранное» и «Обновить».

**Ключ API.** При первом запуске панель объяснит, где его взять:
[console.anthropic.com](https://console.anthropic.com/settings/keys) →
Settings → API Keys → Create Key. Ключ можно вставить прямо в панель, он
сохранится в настройках плагина. Ключ хранится только локально, а
переписка уходит напрямую в API Anthropic.

| Настройка | По умолчанию | |
|---|---|---|
| Ключ Anthropic API | — | `sk-ant-…` |
| Модель | `claude-sonnet-5-5` | Можно `claude-opus-5-5` (умнее) или `claude-haiku-4-5` (дешевле) |
| Сколько последних сообщений читать | 100 | 10–500 |
| Если есть непрочитанные — пересказывать их | да | |
| Язык ответа | русский | русский, English, українська, «как в чате» |
| Подробный дайджест | нет | До 12 пунктов вместо 3–7 |
| Максимум токенов в ответе | 4096 | |
| Адрес API | `https://api.anthropic.com/v1/messages` | Для совместимого прокси, если API недоступен |
| Кнопка ✨ в шапке чата | да | |

Подробности для любопытных:

- Переписка передаётся модели как данные внутри `<transcript>`. Просьбы
  и команды из сообщений модель не выполняет.
- Для моделей 5-го поколения плагин включает серверный запасной вариант
  (`fallbacks: "default"`): если классификатор откажет, API само повторит
  запрос на другой модели.
- Если прокси не понимает новых полей, плагин сам повторит запрос без них.
- Ошибки 401 (ключ), 404 (модель), 429 (лимит) и 529 (перегрузка) плагин
  показывает понятным текстом.

## Удалённые сообщения (`deleted-alerts`)

Когда собеседник удаляет сообщение, приходит уведомление: кто удалил, где
и что было в сообщении. Клик по уведомлению открывает это место в чате:
AyuGram сохраняет удалённые сообщения, так что их видно. Если удалили
сразу много сообщений (например, очистили историю), приходит одно
уведомление «Удалено N сообщ.» с превью. Если удаления идут сразу в
нескольких чатах (больше трёх), приходит одно общее уведомление, клик по
нему открывает журнал.

- `/deleted` — журнал удалённого, новые сверху, у каждой записи кнопка
  «↪ открыть»;
- `/deleted here` или пункт меню чата «🗑 Удалённые в этом чате (N)» —
  журнал одного чата;
- в журнале есть кнопки «Сохранить в файл»
  (`tdata/plugins_data/deleted-alerts-log.txt`) и «Очистить журнал».

| Настройка | По умолчанию | |
|---|---|---|
| Только личные чаты | да | Выключи, чтобы следить и за группами |
| Следить и за каналами | нет | |
| Не сообщать о своих сообщениях | да | |
| Не сообщать об удалениях у ботов | да | |
| Системное уведомление | да | Иначе всплывающая подсказка в окне |
| Уведомлять без звука | да | |
| Сколько записей хранить в журнале | 300 | |

## Напоминания (`reminders`)

```
/remind 10m купить хлеб
/remind 1h30m созвон с командой
/remind 18:30 забрать посылку
/remind завтра 9:00 отправить отчёт
/remind 25.12 10:00 подарки
/remind через 2 часа позвонить маме
```

Время можно задать так:

- длительность: `10m`, `1h30m`, `2d`, `1w`, а также `10 мин`, `2 часа`, `3д`, `1.5h`;
- время суток: `18:30`. Если это время сегодня уже прошло, напоминание
  сработает завтра;
- день: `завтра`, `послезавтра`, `завтра 9:00`, `25.12`, `25.12 10:00`;
- просто число означает минуты: `/remind 15 чай`.

Если отправить `/remind` ответом на сообщение, напоминание запомнит это
сообщение. В меню любого сообщения есть **«⏰ Напомнить через…»**,
а в меню чата — **«⏰ Напомнить об этом чате…»**.

Когда напоминание срабатывает, приходит уведомление. Клик по нему
открывает нужный чат и сообщение. Напоминания хранятся на диске и
переживают перезапуск. Те, что должны были сработать, пока клиент был
закрыт, сработают при запуске с пометкой «пропущено».

- `/reminders` или `/remind` без аргументов — список с кнопками
  «↪ открыть», «+1 час» и «✕ удалить»;
- `/remind clear` — удалить все;
- пункт главного меню «Напоминания».

| Настройка | По умолчанию | |
|---|---|---|
| Время по умолчанию в окне «Напомнить через…» | `1h` | |
| Дублировать напоминание в Избранное | нет | Со ссылкой на сообщение |
| Уведомлять без звука | нет | |

## Статистика чата (`chat-stats`)

`/stats` или пункт меню чата **«📊 Статистика чата»** загружает последние
сообщения с сервера и показывает:

- сколько сообщений и за какой период, сколько в среднем в день, самый
  активный день, сколько ответов, пересылок, ссылок и правок;
- кто пишет больше всех: место, число сообщений, доля и полоска;
- активность по часам: 24 строки с текстовым графиком;
- активность по дням недели;
- частые слова без предлогов и союзов (русские и английские стоп-слова
  плюс свои);
- любимые эмодзи и типы медиа.

Внизу кнопки «Скопировать отчёт», «Отправить в этот чат» (с
подтверждением) и «Посчитать по 2N сообщениям». `/stats 3000` задаёт
число сообщений вручную, максимум 5000.

| Настройка | По умолчанию | |
|---|---|---|
| Сколько последних сообщений анализировать | 1000 | |
| Сколько авторов показывать | 8 | |
| Сколько слов показывать | 12 | |
| Свои стоп-слова | — | Через пробел или с новой строки |

## Ключевые слова (`keyword-alerts`)

Присылает уведомление, когда в любом чате пишут нужное слово: твоё имя,
ник, название проекта, «срочно». В уведомлении найденное слово выделено
«ёлочками», клик открывает сообщение.

- `/kw add релиз` — следить за словом;
- `/kw del релиз` — перестать;
- `/keywords` или `/kw` — панель: список слов с кнопкой удаления, поле для
  нового слова, переключатели и последние 20 срабатываний;
- пункт меню чата «🔕 Ключевые слова: не искать здесь» исключает чат.

Слова записываются по одному в строке. Регулярное выражение пишется как
`/шаблон/флаги`, например `/срочн(о|ый)/`. Без флагов поиск идёт без учёта
регистра. Режим «только целые слова» понимает кириллицу: `дамза` не
сработает на «дамзаграм».

| Настройка | По умолчанию | |
|---|---|---|
| Слова или /регулярки/ | — | |
| Искать и в чатах без звука | нет | |
| Только группы и каналы | нет | |
| Не реагировать на свои сообщения | да | |
| Только целые слова | да | |
| Не чаще одного уведомления из чата за N секунд | 10 | Срабатывания всё равно попадают в журнал |
| Системное уведомление | да | |

## Автоответчик (`auto-reply`)

**Выключен по умолчанию**, включи его в **Настройки → Плагины**.

В режиме «не в сети» плагин отвечает в личных чатах заданным текстом,
каждому человеку не чаще раза в N минут (не меньше минуты, чтобы два
автоответчика не отвечали друг другу без конца). Группы, каналы, боты,
Избранное и служебные уведомления Telegram (коды входа) не трогаются. Если
в клиенте несколько аккаунтов, плагин отвечает только на сообщения
активного: ответ уходит от него.

- `/away on` — включить, `/away on Я в отпуске до понедельника` —
  включить со своим текстом на этот раз;
- `/away off` — выключить, `/away` — переключить;
- `/away status` — состояние, расписание и число отправленных ответов;
- пункт главного меню «Автоответчик: включить / выключить».

Ручной режим выключается сам, когда ты пишешь сообщение, с этого
компьютера или с телефона. Свои автоответы плагин активностью не считает.
По расписанию автоответчик включается сам, например ночью.

| Настройка | По умолчанию | |
|---|---|---|
| Текст ответа | «Привет, {name}! Я сейчас не у компьютера…» | `{name}` — имя собеседника |
| Отвечать одному человеку не чаще, чем раз в N минут | 60 | |
| Расписание | — | `23:00-08:00`, несколько интервалов через запятую |
| Отвечать только контактам | нет | |
| Выключать ручной режим, когда я сам пишу | да | |
| Показывать подсказку, когда автоответчик ответил | нет | |

## Текстовые инструменты (`text-tools`)

| Команда | Что делает |
|---|---|
| `/calc 2*(3+4)^2` | Калькулятор: `+ - * / % ^ !`, скобки, `sqrt abs round floor ceil sin cos tan log ln exp min max pow`, `pi`, `e`. Без `eval`, запятая тоже работает как разделитель дробной части |
| `/tr ghbdtn` | Исправить раскладку: «ghbdtn» → «привет», «руддщ» → «hello» |
| `/upper`, `/lower` | ВЕРХНИЙ и нижний регистр |
| `/mock текст` | сПоНжБоБ-рЕгИсТр |
| `/reverse текст` | Текст задом наперёд |
| `/upside текст` | ʇɔʞǝɯ ʚɐнɯоʚǝdǝu |
| `/b64 текст`, `/b64 -d строка` | Base64 в обе стороны, с UTF-8 |
| `/len текст` | Символы, слова, строки |
| `/rand`, `/rand 1 6`, `/rand чай кофе` | Случайное число или выбор из вариантов |
| `/shrug текст` | текст ¯\\\_(ツ)\_/¯ |

Результат команды уходит в чат вместо неё. Если отправить команду без
текста ответом на сообщение, обработается текст того сообщения: результат
покажется подсказкой и скопируется в буфер, в чат ничего не уйдёт.

В меню сообщения есть ещё три пункта:

- **«⌨️ Исправить раскладку»**. Своё сообщение плагин исправит прямо в
  чате, у чужого покажет и скопирует исправленный текст. Если текст похож
  на набранный не в той раскладке, исправление видно прямо в названии пункта;
- **«Скопировать как цитату»**;
- **«Раскодировать base64»** — появляется только у сообщений, похожих
  на base64.

При отправке плагин сам заменяет `:shrug:` на ¯\\\_(ツ)\_/¯, а также
`:lenny:`, `:flip:`, `:unflip:`, `:cool:`, `:why:`, `:hug:` и `:dance:`.

| Настройка | По умолчанию | |
|---|---|---|
| Автозамена :shrug: и других | да | |
| Сам исправлять сообщения, набранные не в той раскладке | нет | Экспериментально: срабатывает, только если текст сплошь из латиницы без гласных, а после перевода похож на русский |
| Результат команд — в поле ввода | нет | Чтобы проверить текст перед отправкой |

## Антиреклама (`anti-ads`)

Скрывает рекламные посты из ленты. Сообщение не удаляется, его просто не
видно. Плагин узнаёт:

- маркировку по закону о рекламе: `erid: …`, «Реклама. ООО …», «Реклама.
  ИНН …», «рекламодатель:»;
- хэштеги `#реклама`, `#ad`, `#ads`, `#sponsored`, `#промо`, `#партнёр`;
- фразы «на правах рекламы», «партнёрский материал»;
- в строгом режиме ещё и «по промокоду», «переходи по ссылке»,
  «подписывайся на канал», розыгрыши, «скидка 50%»;
- твои слова и `/регулярки/`.

По умолчанию плагин работает в каналах. В меню любого канала или группы
есть пункт **«🛡 Антиреклама: выключить здесь (скрыто N)»** или
**«включить здесь»**.

`/antiads` открывает панель:

- сколько постов скрыто за всё время и за сеанс;
- топ каналов по рекламе;
- **«Показать скрытое»**, чтобы на время снять фильтр;
- переключатели «Только каналы» и «Строгий режим»;
- сброс исключений и счётчика.

| Настройка | По умолчанию | |
|---|---|---|
| Свои слова или /регулярки/ | — | |
| Только в каналах | да | В остальных чатах фильтр включается через меню чата |
| Строгий режим | нет | |

## Тема DamZaGram (`damza-theme`)

Перекрашивает фирменными акцентами любую тему: кнопки, ссылки, бейджи,
переключатели, выбранный чат в списке и исходящие сообщения. Фон и
основной текст остаются от твоей темы. Для ночного и дневного режима

сам.

кнопках. Цвет выбранной папки на боковой панели плагин подбирает по её
настоящему фону: в дневной теме по умолчанию панель тёмная.

## Свой плагин вместо встроенного

Встроенный плагин — это обычная папка в `tdata/plugins/<id>/`. Его можно
открыть, почитать и поменять. Если в его `manifest.json` есть
`"builtin": true`, клиент перезапишет твою правку при следующем
обновлении плагина. Чтобы оставить правку, убери эту строку: клиент
перестанет трогать плагин, и он станет твоим. Чтобы вернуть встроенную
версию, удали папку, и при следующем запуске клиент поставит плагин заново.
