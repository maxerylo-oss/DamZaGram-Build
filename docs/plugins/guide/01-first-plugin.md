# 1. Первый плагин

За 15 минут соберём настоящий плагин: команда в чате, пункт контекстного
меню, настройки, хранилище и пара файлов с `import`. По пути разберёмся, как
плагин запускается, перезагружается и где смотреть ошибки.

## Создаём плагин мастером

1. Открой менеджер плагинов: **Настройки → Плагины**, главное меню →
   **Плагины** или `Ctrl+Shift+P` (когда фокус не в поле ввода: там это
   сочетание делает спойлер).
2. Нажми **Создать плагин**. Введи название — «Счётчик слов» — и id
   `word-counter`. Id подставляется из латинских букв названия, для
   русского названия его лучше вписать самому. Автор по умолчанию — твой
   @username.
3. Мастер создаст папку `tdata/plugins/word-counter/`, включит плагин и
   откроет папку. В углу появится тост — плагин уже работает.

В папке лежат:

| Файл | Что это |
|---|---|
| `manifest.json` | Описание плагина и схема настроек |
| `main.js` | Код: ES-модуль с примерами (тост, команда, пункт меню, событие) |
| `jsconfig.json`, `types/*.d.ts` | Подсказки и проверка типов в VS Code |

Открой папку в VS Code (`code .`) — при наборе `dzg.` редактор покажет все
методы API с описаниями.

> Без мастера: создай папку в `tdata/plugins/`, положи туда `manifest.json`
> и `main.js` (пример ниже), нажми **Перезагрузить все** и включи плагин
> переключателем.

## Горячая перезагрузка

Переключатель **«Горячая перезагрузка»** в разделе «Плагины» включён по
умолчанию. Пока он включён:

- каждое сохранение файла в папке плагина перезапускает плагин (с тостом
  «Плагин перезагружен») — обычно быстрее, чем успеваешь переключиться в
  клиент;
- ошибка загрузки или исключение в обработчике показывается тостом
  «Ошибка плагина: id» с первой строкой текста;
- полный стек — в **Логе** плагина и в окне **DevTools**.

Каждый перезапуск начинается с чистого листа: переменные обнуляются,
команды и кнопки регистрируются заново. Сохранять между перезапусками
нужно через `dzg.storage`.

## Манифест

Замени `manifest.json`:

```json
{
  "id": "word-counter",
  "name": "Счётчик слов",
  "version": "1.0.0",
  "author": "@wetakush",
  "description": "Команда /words и пункт меню «Посчитать слова»",
  "main": "main.js",
  "settings": [
    { "key": "showChars", "type": "bool", "title": "Показывать и символы", "default": true },
    { "key": "minLength", "type": "number", "title": "Минимальная длина слова", "default": 1, "min": 1, "max": 20, "integer": true }
  ]
}
```

Из `settings` клиент построит окно **Настройки** плагина: чекбокс и поле с
проверкой диапазона. Все поля манифеста описаны в
[README](../README.md#манифест).

## Код

Замени `main.js`:

```js
// Счётчик слов — пример первого плагина DamZaGram.
const countWords = (text) => {
  const min = Number(dzg.settings.get('minLength')) || 1;
  return text.split(/[^\p{L}\p{N}'-]+/u).filter((w) => w.length >= min).length;
};

const describe = (text) => {
  const words = countWords(text);
  return dzg.settings.get('showChars')
    ? `${words} слов, ${text.length} символов`
    : `${words} слов`;
};

// 1. Пункт в контекстном меню сообщения (правый клик по сообщению).
dzg.ui.addMessageMenuItem({
  title: 'Посчитать слова',
  when: (message) => message.text.length > 0,
  onClick(message) {
    dzg.ui.toast(describe(message.text), 'Счётчик слов');
    const total = dzg.storage.get('total', 0) + countWords(message.text);
    dzg.storage.set('total', total);
  },
});

// 2. Команда: «/words текст» в любом чате. Сообщение не уйдёт в чат.
dzg.commands.register('words', {
  description: 'Посчитать слова в тексте или в последнем сообщении чата',
  run({ rest, chat }) {
    const text = rest || dzg.messages.loaded(chat, 1).map((m) => m.text).join('');
    dzg.ui.toast(text ? describe(text) : 'Нечего считать');
  },
});

// 3. Событие: плагин загрузился.
dzg.on('ready', () => {
  console.log('Счётчик слов готов, всего посчитано:', dzg.storage.get('total', 0));
});
```

Сохрани — плагин перезапустится. Проверь:

- правый клик по любому сообщению → **Посчитать слова**;
- в поле ввода `/words раз два три` и Enter — тост «3 слов, 13 символов»,
  в чат ничего не ушло;
- **Настройки** в карточке плагина → сними «Показывать и символы» →
  **Сохранить** — следующий подсчёт без символов.

## Что тут происходит

- `main.js` выполняется **один раз** при загрузке, сверху вниз. Он ничего не
  «делает» сам — только регистрирует обработчики. Клиент вызывает их позже.
- `dzg.ui.addMessageMenuItem` добавляет пункт в меню сообщения. `when`
  решает, показывать ли пункт для конкретного сообщения, — он вызывается при
  каждом открытии меню, поэтому должен быть быстрым.
- `dzg.commands.register('words', …)` перехватывает отправку текста,
  начинающегося с `/words`. В `run` приходят `args` (слова), `rest` (всё
  после команды строкой), `chat` и `replyTo`.
- `dzg.settings.get(key)` всегда возвращает актуальное значение — его не
  нужно кешировать. Если нужно реагировать на изменения сразу, подпишись на
  `settings.changed`.
- `dzg.storage` — маленькая база «ключ → JSON» для плагина, сохраняется на
  диск сразу при `set`.

## Делим код на файлы

`main.js` — ES-модуль, поэтому можно `import`:

```js
// lib/text.js
export const countWords = (text, min = 1) =>
  text.split(/[^\p{L}\p{N}'-]+/u).filter((w) => w.length >= min).length;

export const plural = (n, one, few, many) => {
  const a = n % 10, b = n % 100;
  if (a === 1 && b !== 11) return one;
  if (a >= 2 && a <= 4 && (b < 10 || b >= 20)) return few;
  return many;
};
```

```js
// main.js
import { countWords, plural } from './lib/text.js';

const describe = (text) => {
  const n = countWords(text, Number(dzg.settings.get('minLength')) || 1);
  return `${n} ${plural(n, 'слово', 'слова', 'слов')}`;
};
```

Горячая перезагрузка следит за всеми файлами папки плагина, включая
подпапки вроде `lib/` (до 256 путей на плагин; скрытые папки и
`node_modules` пропускаются), а также за появлением и удалением файлов.
Сохранил любой файл — плагин перезапустился. Файлы, которые плагин пишет
сам через `dzg.fs.write`, перезагрузку не вызывают.

## Асинхронный код

`async`/`await` работают везде. Например, посчитаем слова в последних 200
сообщениях чата — история приходит с сервера:

```js
dzg.commands.register('wordstat', async ({ chat }) => {
  const history = await dzg.messages.history(chat, { limit: 200 });
  const total = history.reduce((sum, m) => sum + countWords(m.text), 0);
  dzg.ui.toast(`В последних ${history.length} сообщениях ${total} слов`);
});
```

Пока плагин ждёт ответа сервера, клиент работает как обычно: `await` не
блокирует интерфейс. Ошибка в `async`-обработчике не потеряется — она
попадёт в лог плагина.

## Куда смотреть, если не работает

1. Карточка плагина: красный текст под описанием — последняя ошибка.
2. Кнопка **Лог** — всё, что плагин писал через `console.log`, и полные
   стеки ошибок.
3. Кнопка **Консоль** — DevTools: выполни `dzg.settings.all()` или
   `dzg.chats.current()` прямо в контексте плагина.

Подробно — в гайде [«Отладка»](09-debugging.md).
