# 5. Интерфейс

Плагин может встроиться в интерфейс клиента почти где угодно: от тоста до
собственной боковой панели, а через дерево виджетов — достать и изменить
любой элемент окна. Все `add*` возвращают функцию, которая убирает
добавленное, а при выгрузке плагина всё убирается само. Подробный
справочник — [api/ui.md](../api/ui.md).

## Тосты

```js
dzg.ui.toast('Готово');
dzg.ui.toast('Скопировано 3 ссылки', 'Мой плагин');   // с заголовком
```

Тост — короткое сообщение внизу окна, исчезает само. Для важного с
действием по клику — [уведомления](#уведомления).

## Окна: alert, confirm, prompt, box

```js
await dzg.ui.alert('Плагин обновлён до версии 2.0', 'Что нового');

if (await dzg.ui.confirm('Удалить 15 сообщений?', { confirmText: 'Удалить', danger: true })) {
  dzg.messages.delete(chat, ids, { revoke: true });
}

const name = await dzg.ui.prompt('Как назвать папку?', { placeholder: 'Название', value: 'Работа' });
if (name !== null) console.log('Ввели', name);   // null — нажали «Отмена»
```

`box` — окно из полей, чекбоксов и кнопок:

```js
const result = await dzg.ui.box({
  title: 'Новое напоминание',
  text: 'Напомню в «Избранном»',
  inputs: [
    { id: 'text', placeholder: 'О чём напомнить' },
    { id: 'minutes', placeholder: 'Через сколько минут', value: '30' },
  ],
  toggles: [{ id: 'silent', text: 'Без звука', checked: true }],
  buttons: [
    { id: 'ok', text: 'Создать' },
    { id: 'cancel', text: 'Отмена' },
  ],
});
if (result.button === 'ok') {
  const { text, minutes, silent } = result.values;
  dzg.messages.send(dzg.users.self(), String(text), {
    scheduleDate: new Date(Date.now() + Number(minutes) * 60e3),
    silent: Boolean(silent),
  });
}
```

`button` — id нажатой кнопки или `'cancel'`, если окно закрыли. `values` —
значения полей (строки) и чекбоксов (`true`/`false`) по их `id`. Поле с
`multiline: true` — многострочное.

## Контекстные меню

Пункт в меню сообщения (правый клик по сообщению) и в меню чата (правый
клик в списке чатов и меню «⋮» в шапке):

```js
dzg.ui.addMessageMenuItem({
  title: 'Копировать как Markdown',
  when: (m) => m.text.length > 0,
  onClick: (m) => dzg.clipboard.set(dzg.messages.format(m, 'markdown')),
});

dzg.ui.addChatMenuItem({
  title: (chat) => `Скопировать id ${chat.tgId}`,   // заголовок может быть функцией
  when: (chat) => chat.type !== 'user',
  onClick: (chat) => dzg.clipboard.set(String(chat.tgId)),
});
```

`when` и `title` вызываются при каждом открытии меню — делай их быстрыми и
синхронными. `onClick` может быть `async`.

## Главное меню

```js
dzg.ui.addMainMenuItem({
  title: 'Мой дашборд',
  icon: 'stats',
  onClick: () => openDashboard(),
});
```

Пункты плагинов идут в конце главного меню (☰) после разделителя. Меню
закрывается перед вызовом `onClick`.

## Кнопка в шапке чата

```js
dzg.ui.addTopBarButton({
  icon: 'translate',
  tooltip: 'Перевести последние сообщения',
  when: (chat) => chat.type === 'group' || chat.type === 'channel',
  onClick: (chat) => translateLast(chat),
});

dzg.ui.addTopBarButton({ text: 'Aa', tooltip: 'Регистр', onClick: (chat) => {} });
```

Кнопки встают справа в шапке, рядом с поиском, и выглядят как родные.
Вместо иконки можно дать короткий `text`. `when(chat)` вызывается при каждом
обновлении шапки; если условие зависит от состояния плагина, после его
изменения вызови `dzg.ui.refreshButtons()`.

### Иконки

`icon` — имя из набора клиента, они перекрашиваются вместе с темой. Полный
список — `dzg.ui.icons()` (около сотни): `search`, `settings`, `edit`,
`delete`, `copy`, `link`, `pin`, `mute`, `archive`, `info`, `stats`, `bot`,
`star`, `bell`, `lock`, `user`, `users`, `photo`, `file`, `download`,
`reply`, `forward`, `translate`, `palette`, `night`, `timer`, `schedule`,
`emoji`, `reactions`, а ещё `ghost` и `streamer` из AyuGram.

## Поле ввода

```js
const draft = dzg.ui.compose.get();   // { chat, text } или null
dzg.ui.compose.set('Новый текст');    // заменить всё, курсор в конец
dzg.ui.compose.insert(' 🙂');         // вставить в позицию курсора
dzg.ui.compose.focus();               // активировать окно и поле

dzg.ui.compose.addButton({
  icon: 'font',
  tooltip: 'Исправить раскладку',
  onClick() {
    const current = dzg.ui.compose.get();
    if (current) dzg.ui.compose.set(fixLayout(current.text));
  },
});
```

«Текущее поле» — поле активного окна, в котором фокус (или где он был
последним). Работает в обычных чатах, темах форумов, ответах и отложенных.
Изменения текста приходят событием `compose.changed`.

## Горячие клавиши

```js
dzg.ui.addShortcut('Ctrl+Shift+T', () => dzg.chats.open(dzg.users.self()));
dzg.ui.addShortcut('F8', () => dzg.ui.toast('F8!'));
```

Синтаксис Qt: `Ctrl`, `Shift`, `Alt`, `Meta` и клавиша через `+`. Работает
во всех окнах клиента, и сочетание плагина важнее сочетаний самого клиента
— выбирай аккуратно (`Ctrl+K` уже занят командной палитрой, `Ctrl+Shift+P`
— менеджером плагинов). Пока фокус в текстовом поле, сочетания без
`Ctrl`/`Alt`/`Meta` не срабатывают (кроме F-клавиш). Аккорды
`'Ctrl+K, Ctrl+C'` не поддерживаются — бросается исключение.

## Уведомления

```js
dzg.ui.notify({
  title: 'Новый заказ',
  text: 'Паша: хочу два кофе',
  onClick: () => dzg.chats.open(chat, messageId),
});
dzg.ui.notify('Синхронизация завершена');
dzg.ui.notify({ text: 'Тихое уведомление', silent: true });
```

Уведомление появляется поверх окна клиента на 5 секунд, с кнопкой
«Открыть», если есть `onClick`. Без `silent` играет звук уведомлений и
мигает значок на панели задач, если окно неактивно. Это не системное
уведомление ОС: при свёрнутом окне пользователь увидит только мигание
значка и услышит звук.

## Ссылки

```js
dzg.ui.openLink('https://t.me/wetakush');      // внутри клиента
dzg.ui.openLink('tg://resolve?domain=durov');  // как клик по ссылке в сообщении
dzg.openUrl('https://github.com');             // всегда во внешнем браузере
```

## Боковая панель

Колонка справа в главном окне, как профиль чата. Чат сужается, панель не
перекрывает его.

```js
const panel = dzg.ui.panel({ title: 'Быстрые ответы', width: 320 });

panel.addLabel('Нажми, чтобы вставить', { muted: true });
for (const reply of ['Скоро буду', 'Перезвоню', 'Спасибо!']) {
  panel.addButton(reply, () => dzg.ui.compose.insert(reply), { style: 'row', icon: 'reply' });
}
panel.addSeparator();
const input = panel.addInput({
  placeholder: 'Новый ответ (Enter)',
  onSubmit(text) { panel.addButton(text, () => dzg.ui.compose.insert(text), { style: 'row' }); input.setText(''); },
});
panel.addToggle('Отправлять сразу', false, (checked) => dzg.storage.set('sendNow', checked));
panel.on('close', () => console.log('панель закрыли'));
```

| Метод | Что добавляет |
|---|---|
| `addLabel(text, { bold, muted })` | Текст; потом `label.setText()` |
| `addButton(text, onClick, { style, icon })` | Кнопку: заполненную, `'light'` или строку `'row'` |
| `addInput({ placeholder, value, multiline, onSubmit, onChange })` | Поле ввода; текст — `input.text()` |
| `addToggle(text, checked, onChange)` | Переключатель |
| `addSeparator()`, `addSkip(px)` | Разделитель и отступ |
| `clear()`, `setTitle()`, `setWidth()`, `show()`, `scrollToBottom()`, `close()` | Управление панелью |

У плагина одна панель: повторный `dzg.ui.panel()` вернёт её же. Панели
разных плагинов становятся вкладками. Переключать удобно так:

```js
let panel = null;
dzg.ui.addTopBarButton({
  icon: 'stats',
  onClick: (chat) => {
    if (panel && panel.isOpen()) return panel.close();
    panel = dzg.ui.panel({ title: 'Статистика' });
    panel.addLabel(chat.name, { bold: true });
  },
});
```

## Дерево виджетов: доступ ко всему

Весь интерфейс клиента — дерево виджетов Qt, и плагин видит его целиком.
`Widget` — слабая ссылка: если виджет удалён, методы просто ничего не делают,
а `valid()` возвращает `false`.

```js
const win = dzg.ui.mainWindow();
console.log(JSON.stringify(win.dump(3), null, 2));   // структура на 3 уровня

for (const bar of dzg.ui.find('TopBarWidget')) {
  console.log(bar.className(), bar.geometry());      // 'HistoryView::TopBarWidget', { x, y, width, height }
}

const focused = dzg.ui.focused();                    // виджет с фокусом
focused?.typeText('напечатано плагином');
```

Что можно делать с любым виджетом:

| Группа | Методы |
|---|---|
| Кто это | `className()`, `classChain()`, `name()`, `setName()`, `valid()` |
| Где | `geometry()`, `globalGeometry()`, `setGeometry()`, `move()`, `resize()` |
| Видимость | `visible()`, `show()`, `hide()`, `setVisible()`, `setOpacity(0..1)`, `raise()`, `lower()` |
| Состояние | `setEnabled()`, `setFocus()`, `update()` |
| Дерево | `parentWidget()`, `window()`, `childWidgets()`, `find(class?, name?)`, `childAt(x, y)` |
| Qt-свойства | `prop(name)`, `setProp(name, value)`, `propNames()` |
| Ввод | `click(x, y)`, `typeText(text)` |
| Текст | `text()`, `setText()` — для полей, лейблов, кнопок |
| Прочее | `grab(path)` — скриншот в PNG, `dump(depth)`, `destroy()` |

`find` сравнивает имя класса целиком (`HistoryView::TopBarWidget`) или по
последней части (`TopBarWidget`). Удалять (`destroy`) виджеты клиента
опасно — лучше прятать. Всё, что спрятал или сдвинул, верни в `unload`:

```js
const hidden = dzg.ui.find('TopBarWidget');
hidden.forEach((w) => w.hide());
dzg.on('unload', () => hidden.forEach((w) => w.show()));
```

Путь в `grab` лучше давать абсолютный: `w.grab(dzg.plugin.dataDir + 'shot.png')`.

## Свои виджеты

```js
const card = dzg.ui.create('panel', null, {
  x: 24, y: 80, width: 260, height: 132, color: '#E60F1011', radius: 14,
});
dzg.ui.create('label', card, { x: 16, y: 12, width: 228, height: 24, text: 'DamZaGram' });
const field = dzg.ui.create('input', card, { x: 16, y: 40, width: 228, height: 40, placeholder: 'Текст' });
dzg.ui.create('button', card, {
  x: 16, y: 86, width: 110, height: 34, text: 'Отправить',
  onClick: () => dzg.messages.send(dzg.chats.current(), field.text()),
});
dzg.ui.create('button', card, {
  x: 134, y: 86, width: 110, height: 34, text: 'Закрыть', style: 'light',
  onClick: () => card.destroy(),
});
```

Типы: `label`, `button` (`style: 'light'` — вторичная), `input`
(`multiline`, `placeholder`), `checkbox` (`checked`), `panel` (`color`
`#RRGGBB`/`#AARRGGBB`, `radius`). `parent: null` — главное окно, иначе любой
`Widget`, в том числе виджет клиента. События: `click`, `change`, `submit`,
`destroyed` — через `onClick`/`onChange`/`onSubmit` в свойствах или
`widget.on(event, fn)`. Свои виджеты выглядят как стандартные элементы
Telegram и перекрашиваются с темой. Для большинства задач удобнее
[боковая панель](#боковая-панель) — она сама раскладывает элементы.

## Тема и ночной режим

Любой цвет палитры можно поменять на лету:

```js
dzg.theme.set('windowBgActive', '#C8F135');
dzg.theme.setMany({
  msgOutBg: '#1d2a12',
  msgOutBgSelected: '#2a3d1a',
  historyLinkOutFg: '#C8F135',
});
dzg.on('unload', () => dzg.theme.reset());   // вернуть палитру
```

Имена цветов — ключи `.tdesktop-theme`, полный список в
`Telegram/lib_ui/ui/colors.palette`. Цвет — `#RRGGBB` или `#AARRGGBB`.
`reset()` возвращает палитру, какой она была до первого изменения
плагинами.

Ночной режим и язык:

```js
dzg.app.isNightMode();            // true / false
dzg.app.setNightMode(true);       // переключится после текущего обработчика
dzg.app.language();               // { id: 'ru', baseId: '', name: 'Русский' }
dzg.on('theme.changed', ({ night }) => applyColors(night));
```

После переключения ночного режима клиент загружает другую палитру, поэтому
свои цвета нужно применить заново в `theme.changed` — так делает встроенный
плагин [`damza-theme`](../builtins.md).
