# Экспорт чата (`chat-export`)

Встроенный плагин DamZaGram: сохраняет историю любого чата, группы или канала
в файл. Три формата на выбор, можно сразу несколько:

- **HTML** — одна самодостаточная страница: пузыри сообщений, разделители по
  дням, имена авторов разными цветами, ответы с цитатой (клик ведёт к
  оригиналу), пересылки, реакции, кнопки ботов, жирный, курсив, код, ссылки и
  спойлеры. Светлая и тёмная тема (по системе или принудительно), фирменный
  лаймовый акцент DamZaGram `#C8F135`, внизу строка «Экспортировано
  DamZaGram». Открывается в любом браузере без интернета.
- **Markdown** — читаемая расшифровка: заголовки по дням, `**Автор** · время`,
  ответы цитатой, медиа заглушками (📷 Фото, 🎤 Голосовое сообщение · 0:42,
  📎 Файл · отчёт.pdf · 3,0 МБ…), ссылки. Разметка — обычный CommonMark,
  который понимают GitHub, Obsidian и любые просмотрщики.
- **JSON** — шапка с информацией о чате и массив объектов `Message` ровно в
  том виде, в каком их отдаёт API плагинов (id, автор, текст, entities, медиа,
  ответы, реакции…). Удобно для своих скриптов и анализа.

Сообщения в файле идут по порядку: от старых к новым.

## Как вызвать

- **Меню чата → «📤 Экспорт чата…»** (в списке чатов или в шапке чата) —
  откроется окно с настройками.
- **`/export`** в любом чате — то же окно для текущего чата.
- **`/export` с параметрами** — сразу запускает экспорт, без окна.

### Окно экспорта

| Поле | Что значит |
|---|---|
| Сколько сообщений | `100`, `1000`, `10000`, `все` (или любое число, `5k`) — считая от самых новых |
| С даты / По дату | Необязательный период, `ГГГГ-ММ-ДД` (или `ДД.ММ.ГГГГ`). «По» — включительно |
| HTML / Markdown / JSON | Форматы. Можно отметить несколько — история загрузится один раз |
| Включать служебные сообщения | «Вступил в группу», «закрепил сообщение» и т. п. |

Выбор запоминается до следующего раза.

### Команды

| Команда | Что делает |
|---|---|
| `/export` | Окно экспорта для текущего чата |
| `/export html 1000` | Последние 1000 сообщений в HTML |
| `/export md все` | Вся история в Markdown |
| `/export json html 500` | Последние 500 сразу в JSON и HTML |
| `/export json 2026-01-01 2026-03-31` | Всё за период (одна дата — с неё до сегодня) |
| `/export html все служебные` | Со служебными сообщениями (`-служебные` — без них) |
| `/export stop` | Остановить текущий экспорт |
| `/export list` | Последние экспорты: открыть файл, открыть папку |
| `/export folder` | Открыть папку с экспортами |
| `/export help` | Подсказка по командам |

Порядок слов не важен. Форматы: `html`, `md` (`markdown`), `json`.
Без формата берётся формат из настроек, без числа — число из настроек.

## Прогресс

Пока идёт экспорт, справа открыта панель: полоска с процентом, сколько
сообщений выгружено, скорость, примерное оставшееся время и до какой даты уже
дошли. Кнопки:

- **Остановить и сохранить** — прекратить загрузку и сохранить то, что уже
  выгружено (самые новые сообщения);
- **Отменить экспорт** — прекратить без сохранения.

Панель можно закрыть — экспорт продолжится в фоне. Когда всё готово, приходит
уведомление «📤 Экспорт готов»; кнопка «Открыть» в нём открывает папку с
файлом. В панели результата есть «Открыть HTML/Markdown/JSON», «Открыть
папку», «Скопировать путь», «Отправить в Избранное» и «Экспортировать ещё…».

## Куда сохраняются файлы

`<папка данных плагинов>/chat-export/exports/<Чат>-<ГГГГ-ММ-ДД>.<html|md|json>`

В Linux это `~/.local/share/DamZaGramDesktop/tdata/plugins_data/chat-export/exports/`,
в Windows — `%APPDATA%\DamZaGram Desktop\tdata\plugins_data\chat-export\exports\`.
Если файл с таким именем уже есть, к имени добавится `-2`, `-3`…

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| Формат по умолчанию | HTML | Для `/export` без формата и первого открытия окна |
| Сколько сообщений по умолчанию | 1 000 | 100, 1 000, 10 000 или все |
| Включать служебные сообщения | нет | |
| Ссылки t.me на сообщения | да | Время сообщения становится ссылкой (только супергруппы и каналы) |
| Тема HTML-страницы | как в системе | Или всегда светлая / всегда тёмная |
| Максимум сообщений за один экспорт | 100 000 | Предел для «все», от 1 000 до 1 000 000 |
| Пауза между страницами истории, мс | 150 | Страница — 100 сообщений |
| Открывать файл сразу после экспорта | нет | |

## Как это работает и ограничения

- История грузится с сервера страницами по 100 сообщений
  (`dzg.messages.iterate`). Между страницами плагин делает паузу и отдаёт
  управление клиенту, поэтому интерфейс не подвисает даже на десятках тысяч
  сообщений.
- Если Telegram отвечает `FLOOD_WAIT_N`, плагин ждёт N секунд (в панели идёт
  обратный отсчёт) и продолжает ровно с того же сообщения, без дублей. Сбои
  сети повторяются с нарастающей паузой. Ожидание дольше 15 минут или
  постоянная ошибка останавливают экспорт — загруженное можно сохранить
  кнопкой «Сохранить загруженное».
- Для периода плагин сразу переходит к нужной дате, а не листает всю новую
  историю.
- Медиа не скачиваются — в файле остаются подписи и заглушки с типом,
  размером, длительностью и именем файла.
- Все выбранные форматы собираются в памяти, а память плагина ограничена.
  Примерно 40 млн символов на все форматы вместе — это порядка 80–100 тыс.
  сообщений в HTML. Если файл упирается в предел, экспорт сохраняет самые
  новые сообщения и пишет об этом в файле и в панели: остальное удобно
  выгрузить по периодам.
- Одновременно идёт только один экспорт. Повторный запуск покажет прогресс
  текущего.
- Экспорт работает с активным аккаунтом. Если переключить аккаунт посреди
  экспорта, он остановится (загруженное можно сохранить).
- Файлы хранятся у тебя на диске в открытом виде — относись к ним как к самой
  переписке.

## Примеры

Сохранить переписку с другом за отпуск красивой страницей:

```
/export html 2026-07-01 2026-07-21
```

Выгрузить весь канал для анализа в своих скриптах:

```
/export json все
```

Быстро получить последние 100 сообщений чата текстом и переслать себе: меню
чата → «📤 Экспорт чата…» → 100, Markdown → «Экспортировать», потом
«Отправить в Избранное».
