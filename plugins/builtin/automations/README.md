# Автоматизации (`automations`)

Правила «если → то» без единой строчки кода. Правило ждёт события —
нового сообщения, нужного времени или открытия чата — и выполняет одно или
несколько действий: присылает уведомление, отвечает, ставит реакцию,
пересылает, сохраняет в Избранное, читает чат, выключает звук, дёргает
webhook или показывает «печатает…».

Плагин встроенный и включён по умолчанию, но пока нет ни одного правила,
он ничего не делает. Автор — [@wetakush](https://t.me/wetakush).

## Как начать

1. Напиши в любом чате `/auto` (или главное меню → **Автоматизации**).
   Справа откроется панель со списком правил.
2. Нажми **＋ Добавить правило** и выбери, когда срабатывать: на новое
   сообщение, по расписанию или при открытии чата. Можно взять готовый
   шаблон.
3. Дальше редактор проведёт по шагам: **условия → действия → настройка
   действий → название и защита**. Ошибки он объясняет сразу и оставляет
   введённое на месте.
4. Сохрани. Правило работает сразу. Чтобы сначала посмотреть, что оно будет
   делать, включи **🧪 Пробный режим**.

## Когда срабатывать

### Новое сообщение

Сообщение должно подходить под **все** заполненные условия, пустое поле —
без ограничения.

| Поле | Что писать | Пример |
|---|---|---|
| Чаты | `@username`, id, ссылка `t.me/…`, «текущий» (открытый сейчас чат), «избранное» | `@damzachat, текущий` |
| Отправитель | `@username`, id или часть имени | `@vasya, Маша` |
| Текст содержит | слова через запятую (любое из них, без учёта регистра) или `/регулярка/флаги` | `срочно, asap` · `/^#todo\b/` |
| Медиа | фото, видео, гиф, стикер, голосовое, кружок, аудио, файл, опрос; «любое» или «нет» (только текст) | `голосовое, кружок` |

Переключатели: **входящие** и **мои исходящие** (по умолчанию только
входящие), типы чатов — **личные и боты**, **группы**, **каналы**.
Регулярка без флагов ищет без учёта регистра. id чата можно писать и в
стиле Bot API (`-1001234567890`).

### По расписанию

- `09:00` — каждый день в 9:00, можно несколько: `09:00, 18:30`;
- `30m`, `30`, `каждые 15 мин` — каждые N минут; `2h`, `раз в час` — каждые
  N часов (от минуты до недели);
- переключатель «Только по будням».

Чаты в правиле по расписанию — это **куда** писать текст, где читать,
выключать звук или показывать «печатает…». Уведомлению и webhook чаты не
нужны. Если клиент был закрыт или компьютер спал, запуск в заданное время
(`09:00`) догоняется, только если опоздал не больше чем на 10 минут, и один
раз, а не за каждый пропуск. Правило «каждые N минут» после такой паузы
срабатывает один раз и дальше идёт по своему интервалу. После включения
правила (или всех автоматизаций) отсчёт начинается заново — пропущенное за
время выключения не выполняется.

### Открытие чата

Срабатывает, когда ты открываешь подходящий чат. Фильтры — список чатов и
типы чатов.

## Действия

| Действие | Что делает |
|---|---|
| 🔔 Уведомление | Всплывающее уведомление с твоим текстом. Клик открывает сообщение или чат |
| ↩️ Ответить текстом | Ответ на сообщение (по расписанию и при открытии чата — просто сообщение в чат) |
| 👍 Реакция | Ставит эмодзи-реакцию на сообщение |
| ↪️ Переслать в чат | Пересылает сообщение в выбранный чат (`@username`, id или «избранное») |
| ⭐ В Избранное | Пересылает сообщение в Избранное; если пересылка запрещена — кладёт туда копию текста |
| ✅ Прочитать чат | Отмечает чат прочитанным (уважает режим призрака AyuGram) |
| 🔕 Без звука | Выключает уведомления чата на N часов (можно `0,5`) |
| 🌐 Webhook | `POST` с JSON на твой адрес (ниже — что внутри) |
| ✍️ «печатает…» | Показывает собеседникам статус «печатает…» |

В текстах уведомления и ответа можно подставлять:

| | |
|---|---|
| `{sender}` | имя отправителя |
| `{chat}` | название чата |
| `{text}` | текст сообщения (для медиа без подписи — `[фото]`, `[голосовое]`…) |
| `{time}`, `{date}` | время `14:05` и дата `12.10.2026` |
| `{rule}` | название правила |

### Что уходит в webhook

```json
{
  "source": "DamZaGram",
  "plugin": "automations",
  "rule": { "id": "r3", "name": "Деплой" },
  "trigger": "message",
  "time": "2026-10-12T11:05:00.000Z",
  "chat": { "id": "…", "tgId": 123, "name": "DamZaGram Chat", "username": "damzachat", "type": "group" },
  "message": { "id": 4001, "text": "деплой готов", "date": 1791800700, "out": false,
               "fromId": "…", "fromName": "Петя", "media": null, "replyToId": 0, "link": "https://t.me/…" }
}
```

Для расписания `message` равен `null`, а в `chats` — чаты правила. Ответ
сервера не читается; код не из 2xx и сетевые ошибки попадают в журнал.
Одновременно в пути не больше 4 запросов, таймаут — 15 секунд.

## Защита от спама и петель

- **Лимит на правило.** По умолчанию не больше 5 срабатываний в минуту
  (задаётся у каждого правила, 1–60). Лишние пропускаются, в журнал
  пишется одна запись в минуту.
- **Общий лимит** на все правила вместе — 30 в минуту (настройка).
- **Общий выключатель.** `/auto off` мгновенно останавливает всё, включая
  расписание; `/auto on` — включает. Он же — первый переключатель в панели
  и в настройках плагина.
- **Свои сообщения** запускают правило, только если в нём включено «Мои
  исходящие сообщения».
- **Боты и каналы.** Ответ, реакция и «печатает…» не уходят в чаты с
  ботами, в каналы и на сообщения от ботов и каналов, пока это не
  разрешено в правиле. Уведомление, пересылка, Избранное, webhook
  работают везде.
- **Защита от петель.** После того как правило что-то написало в чат
  (ответ, пересылка, Избранное), этот чат 10 секунд «остывает»: твои
  сообщения в нём не запускают правила, а правила, которые отвечают, на
  входящие там молчат. Два автоответчика не устроят пинг-понг.
- **По расписанию** отправлять сообщения можно не чаще раза в 5 минут.
- **Старые сообщения** (старше 2 минут — догрузка после сна) и служебные
  уведомления Telegram (коды входа) правила не трогают никогда.
- **Несколько аккаунтов.** Правила реагируют только на сообщения
  активного аккаунта — действия идут от него же.
- **🧪 Пробный режим** у правила: ничего не делается, в журнал пишется, что
  было бы сделано.

## Проверка правила

У каждого правила в панели есть кнопка **Проверить на последнем сообщении**
(у расписания — «Проверить и выполнить сейчас», у открытия чата — «на
открытом чате»). Окно покажет, какие условия прошли ✅ и какие нет ❌, и что
правило сделает. Если подходит — кнопка **Выполнить сейчас** (с учётом
лимитов и пробного режима).

В меню любого сообщения есть **⚡ Какие правила сработают?** — список всех
правил с причиной, почему каждое сработает или нет. То же для последнего
сообщения открытого чата — `/auto test`.

## Команды

| Команда | |
|---|---|
| `/auto` | Панель правил |
| `/auto add` | Сразу к выбору нового правила и шаблонам |
| `/auto off`, `/auto on` | Остановить все правила / запустить снова |
| `/auto test` | Какие правила сработали бы на последнее сообщение этого чата |
| `/auto export` | Скопировать все правила в буфер обмена (JSON) |
| `/auto import` | Добавить правила из буфера обмена |

Меню: главное меню → **Автоматизации**; меню чата → **⚡ Правило для этого
чата…** (редактор с уже подставленным чатом); меню сообщения → **⚡ Какие
правила сработают?**

## Панель

- общий выключатель и сводка;
- правила: переключатель вкл/выкл, условия и действия одной строкой,
  сколько раз сработало и когда последний раз, пропуски по лимиту,
  следующий запуск расписания, кнопки «Проверить», «Изменить», «Удалить»;
- журнал: последние 15 записей (✓ выполнено, 🧪 пробно, ⏸ пропущено,
  ⚠ ошибка), «Очистить журнал»;
- экспорт и импорт.

## Экспорт и импорт

`/auto export` кладёт в буфер JSON вида
`{ "type": "damzagram-automations", "version": 1, "rules": [ … ] }` — без
счётчиков и внутренних id. `/auto import` принимает такой JSON, массив
правил или одно правило. Каждое правило проверяется: неизвестные действия
и поля отбрасываются, лимиты и интервалы приводятся к допустимым,
испорченные правила пропускаются. **Импортированные правила добавляются
выключенными** — проверь и включи нужные. Одинаковые названия получают
номер: «Срочное (2)».

## Примеры

- **Срочное → уведомление.** Сообщение · текст `срочно, asap, важно` →
  🔔 «🔥 {sender} · {chat}: {text}».
- **Голосовые в Избранное.** Сообщение · только личные · медиа
  `голосовое, кружок` → ⭐ в Избранное.
- **Задачи из рабочего чата.** Сообщение · чаты `@team` · текст
  `/^#todo\b/` → ↪️ переслать в «избранное» + 👍 реакция.
- **Доброе утро.** Расписание `09:00` · по будням → 🔔 «Доброе утро!
  Сегодня {date}».
- **Сводка в свой сервис.** Сообщение · отправитель `@boss` → 🌐 webhook
  `https://example.com/hook`.
- **Читать каналы при открытии.** Открытие чата · только каналы →
  ✅ прочитать.
- **Автоответ в личке.** Сообщение · личные · текст `привет` → ↩️ «Привет,
  {sender}! Отвечу чуть позже.» Начни с пробного режима и лимита 1–2 в
  минуту.

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| Автоматизации работают | да | Общий выключатель, то же — `/auto on/off` |
| Лимит нового правила | 5 в минуту | Подставляется в редакторе |
| Всего срабатываний в минуту | 30 | На все правила вместе |
| Уведомления правил без звука | нет | |
| Сколько записей хранить в журнале | 200 | 20–2000 |

## Ограничения

- Работает, пока открыт клиент: расписание не выполняется, когда DamZaGram
  закрыт (пропущенный запуск в заданное время догоняется, только если
  опоздал не больше чем на 10 минут). Точность расписания — около 15 секунд.
- Чаты по `@username` в условиях сравниваются по юзернейму; в расписании и
  пересылке юзернейм при сохранении превращается в чат, поэтому чат
  должен существовать.
- Отредактированные и удалённые сообщения правила не запускают — только
  новые.
- Не больше 200 правил, 12 действий в правиле и 50 чатов или
  отправителей в списке.
- 10 секунд после того, как правило написало в чат, твои сообщения в нём
  не запускают правила, а отвечающие правила там молчат — это защита от
  петель, она намеренная. Такие пропуски видны в журнале.
- Данные: правила и журнал — `tdata/plugins_data/automations.json`.
