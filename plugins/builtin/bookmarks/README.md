# Закладки (`bookmarks`)

Встроенный плагин DamZaGram. Автор — [@wetakush](https://t.me/wetakush).
Включён по умолчанию.

Любое сообщение можно положить в закладки, дописать к нему заметку и
теги, а потом найти за пару секунд. Это удобнее, чем пересылать всё в
«Избранное»: исходное сообщение остаётся на месте, к нему можно вернуться
одним кликом, а заметка и теги хранятся отдельно.

## Как добавить

- **Меню сообщения** → «🔖 В закладки». Откроется окно с двумя полями:
  заметка и теги (`#работа #идея`). Enter в поле заметки сразу сохраняет.
  Хэштеги в конце заметки тоже становятся тегами: «позвонить в пятницу
  #работа» сохранится как заметка «позвонить в пятницу» с тегом `#работа`.
- **Ответом на сообщение**: `/bm add заметка #тег`. Если текста нет и
  включена настройка «Спрашивать заметку», откроется то же окно.

Если сообщение уже в закладках, в его меню вместо «В закладки» будет
«🔖 Убрать из закладок» и «📝 Заметка к закладке…». Если у закладки есть
заметка, перед удалением плагин переспросит.

Что сохраняется: чат и его название, id сообщения, отправитель, дата,
первые 300 символов текста, тип вложения (и имя файла), заметка, теги и
время добавления. Поэтому закладка видна, даже если сообщение потом
удалили.

## Панель закладок

Открывается командой `/bm`, пунктом главного меню **«Закладки»**, кнопкой
🔖 в шапке чата или пунктом меню чата «🔖 Закладки в этом чате (N)».

- В заголовке — число закладок, а при поиске «найдено из всего»:
  `🔖 Закладки (3 из 12)`.
- **Поиск** по тексту, заметке, названию чата, отправителю и типу
  вложения. Все слова должны найтись, регистр и «ё/е» не важны.
  Слово с `#` ищет среди тегов по началу: `#раб` найдёт `#работа`.
- **Кнопки тегов**: самые частые теги с числом закладок. Клик оставляет
  только этот тег, повторный клик снимает фильтр. Редкие теги — через
  поиск `#тег`.
- Список **сгруппирован по чатам**, новые сверху: выше тот чат, где
  закладка свежее. У каждой закладки — автор и дата, текст, заметка, теги
  и кнопки **«↪ Открыть»** (прыжок к сообщению), **«📝 Изменить заметку»**
  и **«✕ Удалить»**. Удалённую закладку можно вернуть кнопкой
  «↩ Вернуть закладку» сверху, пока панель открыта.
- Длинный список показывается страницами: «Показать ещё…».
- Кнопка в шапке чата открывает только закладки этого чата; вернуться ко
  всем — «Показать все чаты».

## Команды

| Команда | Что делает |
|---|---|
| `/bm` или `/bookmarks` | Панель со всеми закладками |
| `/bm текст`, `/bm #тег` | Панель сразу с поиском |
| `/bm here` | Закладки текущего чата |
| `/bm add заметка #тег` | Ответом на сообщение — добавить его в закладки |
| `/bm export` | Сохранить все закладки в Markdown |
| `/bm help` | Короткая справка |

## Экспорт в Markdown

Кнопка «⬇ Экспорт всех закладок в Markdown» в панели или `/bm export`
записывает файл `bookmarks/bookmarks.md` в папку данных плагинов
(`tdata/plugins_data/bookmarks/bookmarks.md`). Каждый экспорт
перезаписывает файл. Путь показывается во всплывающей подсказке, папку
открывает кнопка «📂 Открыть папку с экспортом» в панели, а после
`/bm export` — клик по уведомлению.

Пример:

```markdown
# 🔖 Закладки

Экспорт из DamZaGram 12.10.2026 14:30 · закладок: 2

## 👥 DamZaGram Chat (1)

### Петя · 12.10.2026 13:58

> идея для релиза

- Вложение: 🖼 фото «plan.png»
- Заметка: обсудить на созвоне
- Теги: #идея #работа
- Ссылка: https://t.me/c/…/502
- Добавлено: 12.10.2026 14:02
```

## Удалённые и изменённые сообщения

- Если сообщение удалили, закладка остаётся с сохранённым текстом и
  пометкой «🗑 удалено». AyuGram хранит удалённые сообщения, поэтому
  «Открыть» обычно всё равно приводит к нему. Если чат открыть не
  получилось, плагин так и скажет.
- Если сообщение изменили, текст в закладке обновится (настройка
  «Обновлять текст закладки…»). Удалённые сообщения не трогаются.

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| Спрашивать заметку и теги при добавлении | да | Иначе сообщение попадает в закладки сразу |
| Группировать список по чатам | да | Иначе один общий список с названием чата у каждой записи |
| Порядок в списке | по времени добавления | Или по дате самого сообщения |
| Сколько закладок показывать сразу | 30 | 5–200, остальные — «Показать ещё» |
| Кнопка в шапке чата | да | Видна только в чатах, где есть закладки |
| Обновлять текст закладки при правке | да | |
| Открывать папку после экспорта | нет | |

## Несколько аккаунтов

Закладка помнит аккаунт, в котором её сделали: у разных аккаунтов одни и
те же id чатов и сообщений означают разные переписки. Панель показывает
закладки активного аккаунта и пишет, сколько их ещё в других. Экспорт
сохраняет все.

## Ограничения

- До 5000 закладок; заметка — до 1000 символов, до 10 тегов по 32 символа.
  В тегах остаются буквы, цифры, `_` и `-`.
- Из текста сохраняются первые 300 символов. Сами файлы и фото не
  копируются — только тип вложения и имя файла.
- Ссылки `t.me/…` в экспорте есть только для групп и каналов: у личных
  чатов их не бывает.
- Данные лежат в `tdata/plugins_data/bookmarks.json` и никуда не
  отправляются.
