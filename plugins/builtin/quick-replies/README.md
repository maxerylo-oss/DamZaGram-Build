# Быстрые ответы (`quick-replies`)

Заготовки текста, которые вставляются или отправляются в пару кликов: адрес,
реквизиты, «спасибо», «опаздываю», ответы на частые вопросы. В тексте можно
использовать переменные: имя собеседника, дату, время, буфер обмена, а ещё
вопросы, которые плагин задаст перед вставкой.

Плагин встроенный и включён по умолчанию. Сам он ничего не отправляет:
сообщение уходит, только когда ты нажал кнопку, набрал `/q` или `;;сокращение`.
Автор — [@wetakush](https://t.me/wetakush).

## Как пользоваться

**Кнопка у поля ввода** (значок облачка) открывает панель «⚡ Быстрые ответы».
Повторный клик её закрывает. Ту же панель открывают `/q` и пункт главного меню
«Быстрые ответы».

В панели:

- **поиск** сверху ищет по названию, тексту и сокращению. `;;b` ищет только
  по сокращениям. **Enter** вставляет первый ответ из списка;
- **клик по названию** вставляет ответ в поле ввода, в позицию курсора.
  Остаётся проверить и нажать Enter;
- **«➤ Отправить сразу»** отправляет ответ в открытый чат без поля ввода;
- **«Режим правки»** меняет клики: по названию открывается редактор, под
  каждым ответом появляется «✕ Удалить»;
- внизу, когда поиск пуст: «Новый быстрый ответ», «Экспорт в буфер обмена»,
  «Импорт из буфера обмена» и «Вернуть стандартные», если какие-то из
  стандартных ты удалил.

При первом запуске уже есть четыре ответа:

| Название | Сокращение | Текст |
|---|---|---|
| Приветствие | `;;hi` | Привет, {first}! 👋 |
| Спасибо | `;;ty` | Спасибо, {first}! Очень помогло 🙏 |
| Занят | `;;busy` | Сейчас не могу ответить — напишу, как освобожусь 🙌 |
| Опаздываю | `;;late` | Немного задерживаюсь, буду через {?Через сколько минут?\|10} мин. Извини! |

## Команда `/q`

```
/q                  открыть панель
/q спасибо          отправить «Спасибо» в этот чат вместо команды
/q ty               то же по сокращению
/q спас             хватит начала названия, если подходит только один ответ
/q счёт 1500 ₽      текст после названия подставится вместо {rest}
```

Если отправить `/q` ответом на сообщение, быстрый ответ тоже уйдёт ответом
на него. Если название не нашлось или подходит несколько ответов, плагин
скажет об этом и откроет список. Если команду вызвали без чата (например,
другой плагин через `dzg.commands.run`), ответ вставляется в поле ввода.

## Сокращения `;;`

У ответа может быть сокращение — одно слово из букв, цифр, `_` или `-`.
Если отправить сообщение, которое целиком состоит из `;;сокращения`, вместо
него уйдёт текст быстрого ответа: `;;hi` → «Привет, Вася! 👋». Регистр не
важен, ответ на сообщение сохраняется.

- `смотри ;;hi` не трогается: сообщение должно быть ровно сокращением;
- если такого сокращения нет, сообщение не уходит, текст возвращается в
  поле ввода, а подсказка объясняет, в чём дело. Отправь его ещё раз в
  течение минуты, и оно уйдёт как есть;
- если в ответе есть вопросы `{?…}`, сначала откроется окно с вопросом, а
  потом ответ уйдёт сам.

Выключается настройкой «Разворачивать ;;сокращение при отправке».

## Переменные

| Переменная | Что подставится |
|---|---|
| `{name}`, `{чат}` | Название чата или имя собеседника |
| `{first}`, `{имя}` | Имя собеседника в личке. В группе — имя автора сообщения, на которое отвечаешь. Иначе пусто |
| `{me}`, `{я}` | Твоё имя |
| `{date}`, `{дата}` | Сегодняшняя дата: `12.10.2026` |
| `{time}`, `{время}` | Время: `09:05` |
| `{clipboard}`, `{буфер}` | Текст из буфера обмена |
| `{rest}`, `{текст}` | Текст после названия в `/q название …`. Если `{rest}` в ответе нет, этот текст допишется в конец |
| `{?Вопрос}` | Плагин спросит перед вставкой и подставит ответ |
| `{?Вопрос\|10}` | То же, с ответом по умолчанию |

Если переменная оказалась пустой, плагин убирает лишнюю запятую перед ней:
«Привет, {first}!» в группе превратится в «Привет!». Одинаковые вопросы
задаются один раз, а последний ответ на каждый вопрос запоминается и
предлагается в следующий раз. Неизвестные `{слова}` остаются как есть.

Разметка `**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` `` и
`||спойлер||` работает: в поле ввода её применит сам клиент при отправке, а
когда отправляет плагин (`/q`, «Отправить сразу», `;;`), он разбирает её сам.

## Меню сообщения

**«⚡ Сохранить как быстрый ответ»** есть у любого сообщения с текстом.
Плагин предложит название по первым словам. Сокращение можно добавить сразу,
через пробел: `Адрес ;;addr`. Если ответ с таким названием уже есть,
плагин спросит, заменить ли его текст. Жирный, курсив, зачёркнутый, код и
спойлеры сохраняются как разметка. Скрытые ссылки и премиум-эмодзи
сохраняются простым текстом.

## Импорт и экспорт

«Экспорт в буфер обмена» кладёт все ответы в буфер как JSON. На другом
компьютере скопируй этот текст и нажми «Импорт из буфера обмена». Ответы с
совпадающим названием обновятся, новые добавятся. Если сокращение уже занято
другим ответом, импортированный ответ останется без него.

```json
{
  "type": "damzagram.quick-replies",
  "version": 1,
  "snippets": [
    { "name": "Адрес", "shortcut": "addr", "text": "Москва, ул. Ленина, д. 5, кв. 12" },
    { "name": "Реквизиты", "text": "Карта: {?Какая карта?|Т-Банк}\nПолучатель: {me}" }
  ]
}
```

Импорт понимает и проще: массив `[{ "name": …, "text": … }]`, массив строк
или объект `{ "Название": "Текст" }`.

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| Кнопка быстрых ответов у поля ввода | да | |
| Разворачивать ;;сокращение при отправке | да | |
| Понимать разметку **жирный**, __курсив__, `код`, \|\|спойлер\|\| | да | Когда ответ отправляет сам плагин |
| Закрывать панель после вставки или отправки | да | |
| Порядок в списке | частые сверху | или по алфавиту, или по порядку добавления |

## Примеры

```
Название: Реквизиты     Сокращение: card
Текст:    Номер карты: 2200 0000 0000 0000, {me}. Сумма: {rest}

/q card 1500 ₽   →   Номер карты: 2200 0000 0000 0000, Даня. Сумма: 1500 ₽
```

```
Название: Встреча       Сокращение: meet
Текст:    Договорились: {?Когда?|завтра в 19:00}, {?Где?}. До встречи, {first}! 🤝

;;meet   →   два вопроса, затем «Договорились: завтра в 19:00, у метро. До встречи, Вася! 🤝»
```

```
Название: Ссылка        Текст: Вот, держи: {clipboard}
```

## Ограничения

- До 300 ответов. Текст — до 4096 символов (лимит Telegram), название — до
  64, сокращение — до 32 символов.
- Плагин отправляет не больше 5 сообщений за 10 секунд, а один и тот же
  ответ в один чат — не чаще раза в 2 секунды. Так двойной клик не
  отправит ответ дважды.
- «Отправить сразу» в панели отправляет не ответом на сообщение: панель не
  знает, на что ты отвечаешь. Чтобы ответить, вставь текст в поле ввода
  или используй `/q` и `;;`.
- В группах с темами то, что отправляет плагин (`/q`, «Отправить сразу»,
  `;;` с вопросами или разметкой), без ответа на сообщение уходит в общую
  тему. В нужную тему надёжнее вставить ответ в поле ввода.
- `{first}` — первое слово имени так, как оно видно у тебя: если контакт
  переименован, будет твоё название.
- `;;сокращение` работает в текстовых сообщениях, не в подписях к файлам.
- Фигурные скобки в сохранённом тексте читаются как переменные: `{name}` в
  тексте сообщения тоже заменится.
- Данные лежат в `tdata/plugins_data/quick-replies.json`.
